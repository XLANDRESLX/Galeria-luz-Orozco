📌 Descripción del Proyecto

Galería Luz Orozco es una plataforma web interactiva diseñada como una galería artística digital y catálogo interactivo. La aplicación sirve como vitrina virtual para exponer y difundir el trabajo artístico de Luz Orozco, ofreciendo a los visitantes una experiencia visual cuidada, moderna e intuitiva para explorar las distintas obras y colecciones.

🎯 ¿Para qué sirve?

Exposición y Difusión Artística: Permite visualizar de forma limpia y atractiva las piezas artísticas, cuadros o exposiciones de la autora.

Catálogo Informativo: Proporciona detalles clave sobre cada obra, como título, dimensiones, técnica, descripción y concepto creativo.

Contacto y Conexión: Facilita la interacción entre los entusiastas del arte, coleccionistas o interesados y la artista a través de enlaces directos o formularios.

Presencia Digital: Sirve como el portafolio profesional definitivo de Luz Orozco en el entorno web.

✨ Características Principales

Visualización Interactiva: Interfaz dinámica desarrollada con JavaScript (script.js) y estilos CSS adaptativos (style.css) para ofrecer una navegación fluida.

Diseño Adaptativo (Responsive): Optimizada para ofrecer una correcta visualización tanto en dispositivos móviles como en pantallas de escritorio.

Integración con Servicios backend (Google Apps Script): Incluye funciones conectadas mediante Code.gs para procesar solicitudes, mensajes o peticiones del usuario directamente desde la interfaz.

🛠️ Estructura General del Proyecto

index.html: Estructura principal de la aplicación web y maquetación de la galería.

style.css: Hoja de estilos encargada de la estética visual, diseño responsivo y maquetación general.

script.js: Lógica de interacción en el cliente (animaciones, filtrado de obras, eventos interactivos).

Code.gs: Código de Google Apps Script para gestionar la integración de datos y envíos desde la web.
